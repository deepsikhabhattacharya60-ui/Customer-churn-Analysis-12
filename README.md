# Customer Churn Analysis

## Project Overview
This project analyzes customer subscription data to understand customer churn and identify patterns related to customer cancellations.

## Tools Used
- Microsoft Excel
- Power BI
- Power Query
- DAX

## Project Work
- Cleaned and analyzed customer data.
- Created summaries and KPIs using Excel.
- Built an interactive Power BI dashboard.
- Analyzed churn by contract type, payment method, and internet service.
- Added slicers for interactive filtering.

## Key Findings
The dashboard helps identify customer churn patterns across different contract types, payment methods, and internet services.

## Files Included
- Excel analysis workbook
- Power BI dashboard

## Conclusion
This project helped me practice data cleaning, data analysis, KPI creation, and dashboard development using Excel and Power BI.
